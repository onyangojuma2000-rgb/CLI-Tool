# AI Text Processor

**[Live Demo](https://ai-text-processor-fx0s.onrender.com)**

A web application that uses Claude Haiku 4.5 to process
user-submitted text and generate AI-powered responses.

## Features

- Submit text through a browser interface.
- Process text using Claude Haiku 4.5.
- Display AI-generated results without reloading the page.
- Validate empty inputs.
- Handle API and processing errors.

## Tools

- Python
- Flask
- Anthropic API
- Claude Haiku 4.5
- HTML
- CSS
- JavaScript
